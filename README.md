# tomorrow school — регистрация команд на Raid

Тимлид заполняет фамилию и имя, ник на платформе, ник в Telegram и выбирает время.
Время берётся из Google Sheets; занятое пропадает из формы, двойная запись невозможна
(проверка под блокировкой `LockService`). Когда слоты заканчиваются, форма скрывается
и показывается сообщение «Свободного времени нет».

## Таблица (лист «Слоты»)

| A: Время | B: Тимлид | C: Ник на платформе | D: Telegram | E: Дата записи |
|----------|-----------|---------------------|-------------|----------------|
| 10:00    | Иванов Иван | iivanov | @ivan_dev | … |
| 10:30    |           |                     |             |                |

Пустая колонка B = слот свободен. Чтобы освободить слот, очистите B–E.

## Настройка

1. Новая Google Таблица → **Расширения → Apps Script** → вставить `apps-script/Code.gs`.
2. Запустить функцию `setupSheet` один раз (создаст лист и тестовое время).
3. **Развернуть → Новое развертывание → Веб-приложение**: выполнять как «Я», доступ «Все».
4. URL `/exec` вставить в `API_URL` в `app.js`.
5. Дата рейда задаётся в `EVENT_DATE` в `app.js` — одна строка на всю страницу.

После изменений в `Code.gs`: **Управление развертываниями → ✏️ → Новая версия**.

## Защита

- Один тимлид = одна запись: повтор ФИО, ника на платформе или Telegram отклоняется
  (`ONE_BOOKING_PER_LEAD` в `Code.gs`).
- `@` в Telegram подставляется автоматически, ссылки `t.me/...` превращаются в ник.

## Логотипы
